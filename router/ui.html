    API keys
    
        
    Keys live in the macOS Keychain or mlaude's local secrets file. Only a masked preview is shown here. The router reads keys at startup, so a new key takes effect after a restart.
    
      
    
      
    
      
    
        
    Extra key slots
    
        
    
        
    Named spare keys per service. Activate one to use it instead of the primary key — takes effect after a restart.
